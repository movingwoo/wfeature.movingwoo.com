W-Feature

W-Feature는 KTF·LGT·SKT 규격의 WIPI 콘텐츠를 구동하는 에뮬레이터입니다.

다양한 환경에서 무료로 즐겨보세요.

활발히 개발 중인 베타버전입니다.

다운로드

최신 릴리즈를 불러오는 중…

간단 설치

Windows

압축을 풀고 games/ 폴더에 콘텐츠 파일을 넣은 뒤 start.bat을 실행합니다.
경고창(SmartScreen)이 뜨면 추가 정보 → 실행을 선택합니다.

macOS

압축을 풀고 games/ 폴더에 콘텐츠 파일을 넣은 뒤 start.command를 실행합니다.
처음 한 번은 Control-클릭 → 열기로 실행해야 합니다.

Linux

압축을 풀고 games/ 폴더에 콘텐츠 파일을 넣은 뒤 ./start.sh를 실행합니다.
실행이 안 되면 chmod +x start.sh로 실행 권한을 부여합니다.

Android

내려받은 APK를 열고 알 수 없는 앱 설치를 허용합니다.

iOS

사이드로딩 도구로 IPA를 설치합니다.
설정 → 일반 → VPN 및 기기 관리에서 개발자를 신뢰하도록 설정합니다.
